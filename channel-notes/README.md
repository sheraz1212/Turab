# Channel notes (restored from the PC's `.claude` folder)

Work from the earlier PC sessions ("history wars", "we made it"), kept here so cloud sessions can use it.

## Working rules
- Nothing is saved on the user's PC. Finished videos are delivered in the chat and downloaded from there.
- Videos do not need to be pushed to the repo. Keep **references** (scripts, templates, plans, code) here in the cloud.
- The user writes in Roman Urdu.
